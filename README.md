# Worlds 2026 Tracker

Live bracket, Swiss stage, schedule and in-game stats for the League of Legends World Championship 2026.

Single static page (`index.html`) that pulls from the official LoL Esports schedule and live stats feeds in the browser. No build step.

- **Live card**: series score and a broadcast-style scoreboard (kills, towers, dragons, barons, inhibitors, gold lead), objective timers (Dragon/Elder, Baron, Grubs/Herald spawns, Baron and Elder buffs, inhibitor respawns), a gold-difference graph over the game, and the draft by lane with each player's KDA, CS, level, HP, items and lane gold gap. Can be collapsed to just the scoreboard.
- Between games, the last game's final scoreboard stays up.

The feed has no bans and no player positions, so there's no ban list or minimap.
